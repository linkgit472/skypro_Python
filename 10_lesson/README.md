# Документация проекта

## Описание базового синтаксиса записи и форматирования
Проект использует следующие технологии и синтаксис:
1. **Python**: Основной язык программирования для написания тестов.
2. **Selenium**: Библиотека для автоматизации взаимодействия с веб-браузером.
3. **Pytest**: Фреймворк для написания и запуска тестов.
4. **Allure**: Инструмент для генерации отчетов о выполнении тестов.

### Форматирование кода
- Код форматируется в соответствии со стандартом PEP 8 (стиль написания кода на Python).
- Используются структурированные docstrings для документирования методов и функций.
- Все шаги теста размечаются с помощью `@allure.step` или `with allure.step` для улучшения читаемости отчетов.

---

## Инструкция по запуску тестов для формирования отчета Allure
1. Установите необходимые зависимости проекта:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите тестов с генерацией отчета Allure:
   ```bash
   pytest --alluredir=./allure-results
   ```
   Эта команда выполнит все тестовые сценарии (Калькулятор и Магазин) и сохранит результаты в директорию `./allure-results`.

---

## Инструкция по просмотру сформированного отчета Allure
1. После завершения тестов, чтобы просмотреть отчет, выполните команду:
   ```bash
   allure serve ./allure-results
   ```
   Эта команда запустит локальный сервер и откроет отчет в браузере.

2. В отчете Allure вы увидите:
   - **Название тестов**: Например, `Проверка сложения чисел 7 и 8 с учетом задержки` или `Успешная покупка трех товаров с проверкой итоговой стоимости`.
   - **Описание тестов**: Подробное описание логики проверок (End-to-End сценарии, таймауты, учет задержек, проверка финальных сумм).
   - **Шаги тестов**:
     - Авторизация пользователей и открытие целевых веб-страниц.
     - Динамическое логирование вводимых данных (логины, параметры задержки).
     - Пошаговое добавление товаров в корзину и заполнение персональных данных.
     - Ожидание элементов и считывание итоговых сумм с экрана.
   - **Вложения (Attachments)**: Фактические текстовые значения стоимости и количества товаров, прикрепленные к шагам.
   - **Результат**: Успешное выполнение или ошибка с указанием ожидаемого и фактического результата.
